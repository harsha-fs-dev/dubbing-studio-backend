# 🎙️ Dubbing Studio Management System - Backend

Spring Boot backend for managing a dubbing studio.

## Features
- JWT Authentication
- Artist Management
- Project Management
- Session Scheduling
- Payment Tracking
- Dashboard Statistics
- AI Chatbot

## Run Locally

```bash
mvn spring-boot:run
```

Backend runs at:

```text
http://localhost:8080
```
